# Simple PHP Engine (SPE)

A progressive PHP 8.5 micro-framework tutorial in 9 chapters. Each chapter builds on the previous, demonstrating modern PHP features and design patterns.

## About

SPE is an educational project showcasing modern PHP 8.1-8.5 capabilities through a progressive tutorial series. Starting from a simple single-file framework, it advances to a full-featured CMS with database, authentication, and plugin architecture.

Perfect for developers wanting to learn current PHP best practices without heavyweight frameworks like Laravel or Symfony.

- Website: https://markc.github.io/spe/
- GitHub: https://github.com/markc/spe
- License: MIT

## Quick Start

```bash
git clone https://github.com/markc/spe
cd spe
composer install
php -S localhost:8000
```

Open http://localhost:8000 to see the chapter index.

## Requirements

- PHP 8.5+ (for pipe operator `|>`)
- Composer (for chapters 05-09)
- SQLite (for chapters 07-09)

## Chapters

- 00-Tutorial: Video generation pipeline (Playwright + Piper TTS)
- 01-Simple: Single-file anonymous class with pipe operator basics
- 02-Styled: Custom CSS, dark mode, toast notifications
- 03-Plugins: Plugin architecture, CRUDL pattern
- 04-Views: Model returns data, View returns HTML, Theme wraps it
- 05-Autoload: PSR-4 autoloading via Composer
- 06-Session: Sessions, flash messages, CSRF, POST-only writes
- 07-PDO: SQLite via PDO, prepared statements, QueryType enum, Posts CRUDL
- 08-Auth: Users, roles (enum ACL), login/logout, remember-me
- 09-Blog: Markdown content engine (posts + docs, tags, pagination, self-hosted docs)

## Modern PHP Features

- **Pipe Operator (8.5)**: Elegant data transformation chains using `|>`
- **Asymmetric Visibility (8.4)**: `public private(set)` property declarations
- **Typed Constants (8.3)**: `const string DEFAULT = 'value'`
- **Override Attribute (8.3)**: `#[\Override]` for class inheritance clarity
- **Readonly Classes (8.2)**: Immutable class definitions
- **Enums (8.1)**: Type-safe enum patterns (QueryType: All, One, Col)
- **First-Class Callables (8.1)**: `fn(...)` / `trim(...)` function references
- **Property Hooks (8.4)**: computed `get` properties (Post::$html, $excerpt)
- **NoDiscard (8.5)**: `#[\NoDiscard]` on Db writes

## Architecture

- **URL Pattern**: `?o=Plugin&m=list&i=1&x=json` — o=plugin, m=create/read/update/delete/list, i=id, x=json; all validated in Ctx
- **Request Flow**: `public/index.php → new Init(new Ctx) → {o}Model->{m}() → {o}View->{m}() → Theme → HTML` (or JSON when x=json)
- **Core Framework**: Ctx (validated request), Init (front controller), Plugin (model base), View (HTML base, owns e() escaping), Theme (document), Db (PDO wrapper)
- **Security habit**: validate input (Ctx allow-lists), escape output (View::e), CSRF-checked POST writes, prepared SQL, hashed passwords

## CSS Architecture

Custom framework without Bootstrap (base.css + site.css + base.js):
- base.css is colour-agnostic structure; site.css defines all colours in OKLCH
- CSS custom properties for light/dark theming
- Auto dark mode via `@media (prefers-color-scheme: dark)`
- Manual theme toggle via localStorage
- Responsive mobile-first design
